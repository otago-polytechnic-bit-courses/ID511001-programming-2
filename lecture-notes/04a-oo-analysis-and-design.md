# 04a: OO Analysis and Design

## OO Analysis

**Object-Oriented Analysis (OOA)** is the process of analysing a task (also known as a problem domain) to identify the objects that will interact with the system and the relationships between those objects.

### Steps in OOA

1. **Objects**: Represent entities in the problem domain. Objects are characterised by their state (attributes or properties) and behaviour (methods or operations).
2. **Classes**: Group objects with similar characteristics. Classes define the structure and behaviour of objects.
3. **Use Cases**: Describe the interactions between objects to achieve a specific goal.
4. **Associations**: Define how objects are related to each other.

### Techniques in OOA

1. **Identify Classes and Objects**: Identify the objects in the problem domain and group them into classes. For example, in a library system, you might have classes for `Book`, `Library`, `Member`, etc.
