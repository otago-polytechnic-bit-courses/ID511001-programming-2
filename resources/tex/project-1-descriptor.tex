\subsection*{Functionality - Learning Outcome 1 (55\%)}

\subsubsection*{Part 1 (10\%)}
\begin{itemize}
    \item \textbf{Institution.cs}. 



    \item \textbf{Institution.cs}. This \textbf{public} class should have information such as name, region and country.
    \item \textbf{Department.cs}. This \textbf{public} class should have information such as institution and name. \textbf{Note:} The institution field should be of type \textbf{Institution}.
    \item \textbf{Course.cs}. This \textbf{public} class should have information such as department, code, name, description, credits and fees. \textbf{Note:} The department field should be of type \textbf{Department}.
    \item \textbf{Seeder.cs}. This \textbf{public} class should have three methods to seed the lists of \textbf{Institution}, \textbf{Department} and \textbf{Course} objects. Each list should contain at least three objects. 
\end{itemize}

\subsubsection*{Part 2 (10\%)}
\begin{itemize}
    \item \textbf{CourseAssessmentMark.cs}. This \textbf{public} class should have information such as course and assessment marks. The assessment marks should be a list of integers. This class should also have methods to get all marks, all grades, highest marks, lowest marks, fail marks, average mark and average grade. 
\end{itemize}

For more information on how to calculate the highest, lowest and fail marks, refer to the \textbf{grade table} in the \textbf{Additional Information} section below.

\subsubsection*{Part 3 (10\%)}

\begin{itemize}
    \item The application needs to contain the following \textbf{enums}:
    \begin{verbatim}
public enum EPosition
{
    LECTURER = 0,
    SENIOR_LECTURER = 1,
    PRINCIPAL_LECTURER = 2,
    ASSOCIATE_PROFESSOR = 3,

public enum ESalary
{

    \item \textbf{Person.cs}. This \textbf{public} class should have information such as id, first name and last name. \textbf{Note:} Information should be \textbf{protected} to allow access in derived classes.
    \item \textbf{Learner.cs}. This \textbf{public} class should inherit from \textbf{Person} and have an additional field for course assessment marks. This field should be of type \textbf{CourseAssessmentMark}.
    \item \textbf{Lecturer.cs}. This \textbf{public} class should inherit from \textbf{Person} and have additional fields for position, salary and course. The position field should be of type \textbf{EPosition}, the salary field should be of type \textbf{ESalary} and the course field should be of type \textbf{Course}.
\end{itemize}

\begin{itemize}
    \item \textbf{DataHandler.cs}. This \textbf{public} class should should have methods for reading from and writing to \textbf{learners.txt} and \textbf{lecturers.txt} files.
    \item The \textbf{learners.txt} file contains the following information:
            \begin{verbatim}
1,Alex,Walker,0,90,95,85,15,5

The first value is the \textbf{id}, the second value is the \textbf{first name}, the third value is the \textbf{last name}, the fourth value is the \textbf{course} index (0 for course 1, 1 for course 2, etc.), and the remaining values are the \textbf{assessment marks} for that learner. Each learner has five assessment marks.

4,Emma,Clark,1,100000,0
5,Liam,Harris,2,115000,1
        \end{verbatim}
        \item What do the values represent? The first value is the \textbf{id}, the second value is the \textbf{first name}, the third value is the \textbf{last name}, the fourth value is the \textbf{EPosition} enum (0 for LECTURER, 1 for SENIOR\_LECTURER, etc.), the fifth value is the \textbf{ESalary} enum (85000 for LECTURER, 100000 for SENIOR\_LECTURER, etc.), and the sixth value is the \textbf{course} index (0 for course 1, 1 for course 2, etc.).

\end{itemize}

\subsubsection*{Part 4 (10\%)}
\begin{itemize}
    \item \textbf{Form1.cs}. This \textbf{public} class should have the following functionality:
    \begin{itemize}
        \item Seed the \textbf{institutions}, \textbf{departments} and \textbf{courses} lists by calling methods from the \textbf{Seeder} class.
        \item Read the \textbf{learners.txt} and \textbf{lecturers.txt} files by calling methods from the \textbf{DataReader} class. 
        \item Display the course details when the user clicks the \textbf{Display course details} button. The course details should include the course code, name, description, credits, fees, institution name, region and country, and department name.
        \item Display all marks when the user clicks the \textbf{Display all marks} button. The marks should include the learner id, first name, last name, course code and name, and assessment marks.
        \item Display all grades when the user clicks the \textbf{Display all grades} button. The grades should include the learner id, first name, last name, course code and name, and assessment grades.
        \item Display highest marks when the user clicks the \textbf{Display highest marks} button. The highest marks should include the learner id, first name, last name, course code and name, and highest assessment mark(s).
        \item Display lowest marks when the user clicks the \textbf{Display lowest marks} button. The lowest marks should include the learner id, first name, last name, course code and name, and lowest assessment mark(s).
        \item Display fail marks when the user clicks the \textbf{Display fail marks} button. The fail marks should include the learner id, first name, last name, course code and name, and fail assessment mark(s).
        \item Display average marks when the user clicks the \textbf{Display average marks} button. The average marks should include the learner id, first name, last name, course code and name, and average assessment mark.
        \item Display average grades when the user clicks the \textbf{Display average grades} button. The average grades should include the learner id, first name, last name, course code and name, and average assessment grade.
        \item Display lecturer details when the user clicks the \textbf{Display lecturer details} button. The lecturer details should include the lecturer id, first name, last name, position, institution name, region and country, department name, course code and name, and salary.
        \item Add a learner when the user clicks the \textbf{Add learner} button. The user should be prompted to enter the first name, last name, course and assessment marks 1-5. The learner should be added to the \textbf{learners} list and written to the \textbf{learners.txt} file. 
        \item Add a lecturer when the user clicks the \textbf{Add lecturer} button. The user should be prompted to enter the first name, last name, position and course. The lecturer should be added to the \textbf{lecturers} list and written to the \textbf{lecturers.txt} file. The salary should be calculated based on the position.
        \item \textbf{id} is auto-generated and unique for both learners and lecturers. The id should be the next available number in the list.
        \item When adding a learner or lecturer, the following validation should be performed:
        \begin{itemize}
            \item The first name and last name should not be empty, and should not contain numbers or special characters.
            \item The course should be selected from the list of courses.
            \item The assessment marks should be between 0 and 100.
            \item The position should be selected from the list of positions.
        \end{itemize}
        \item Remove a lecturer when the user clicks the \textbf{Remove a lecturer} button. The user should be prompted to enter the id of the lecturer to remove. If the id is valid, the lecturer should be removed from the \textbf{lecturers} list and \textbf{lecturers.txt} file.
        \item When the user clicks the \textbf{Exit} button, the application should close.
    \end{itemize}
\end{itemize}

\subsubsection*{Part 5 (15\%)}

In parts 1-4, you implemented the core functionality. In this part, you will select four additional features from the list below to implement in your application. Each additional feature has been marked with either \textbf{Medium} or \textbf{Hard}.

\textbf{Search:}
\begin{itemize}
    \item \textbf{Medium} - Search for a learner and lecturer by id, first name or last name. The user should be able to enter a search term and the application should display the matching learners and lecturers. 
    \item \textbf{Medium} - Search for a course by code or name. The user should be able to enter a search term and the application should display the matching courses.
\end{itemize}

\textbf{Sort and Filter:}
\begin{itemize}
    \item \textbf{Medium} - Sort learners and lecturers by id, first name or last name. The user should be able to select the sorting criteria and order (ascending or descending) from a dropdown list.    
    \item \textbf{Medium} - Sort courses by code, name or fees. The user should be able to select the sorting criteria and order (ascending or descending) from a dropdown list.
    \item \textbf{Hard} - Filter learners and lecturers by course. The user should be able to select a course from a dropdown list and the application should display the learners and lecturers for that course.
    \item \textbf{Medium} - Filter learners by assessment mark. The user should be able to enter a minimum and maximum mark and the application should display the learners with marks within that range.
    \item \textbf{Medium} - Filter courses by country. The user should be able to select a country from a dropdown list and the application should display the courses for that country.
\end{itemize}

\textbf{Statistics:}
\begin{itemize}
    \item \textbf{Hard} - Calculate and display the completion rate for each course based on the number of learners who have completed all assessments.
    \item \textbf{Hard} - Calculate and display the average assessment marks and grades for each institution.
    \item \textbf{Medium} - Calculate and display the average salary of all lecturers.
    \item \textbf{Hard} - Calculate and display the total fees collected for each course based on the number of learners enrolled in that course. 
    \item \textbf{Hard} - Calculate and display the percentage of learners who have achieved merit (B-range) and distinction (A-range) grades for each course.
\end{itemize}

\subsection*{Code Quality and Best Practices - Learning Outcome 2 (40\%)}
\begin{itemize}
    \item Naming Conventions (5\%) - File, class, method, variable, constant and property names should be clear, descriptive and consistent across the codebase. 
    \item Documentation and Comments (10\%) - The code should be well-documented using the \textbf{XML} documentation format with comments that explain complex logic and clarify the purpose of classes, methods or complex sections. 
    \item Code Formatting (10\%) - Consistent indentation and spacing should be used across the codebase. It includes ensuring proper indentation for code blocks, following a standard format for braces and adding blank lines between sections.
    \item Dead Code (5\%) - The code should not contain unused or redundant files, classes, methods, variables, constants or properties. Keeping unnecessary code around can lead to confusion, clutter and potential bugs down the line.
    \item Performance and Scalability (10\%) - The code should be optimised for performance, using \textbf{Object-Oriented Programming} principles, efficient algorithms and data structures to minimise bottlenecks.
\end{itemize}
